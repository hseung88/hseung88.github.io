# Hyunseok Seung — Academic Website

Source for [hseung88.github.io](https://hseung88.github.io), built with the [al-folio](https://github.com/alshedivat/al-folio) academic website theme.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

The site is deployed by `.github/workflows/deploy.yml` when changes are pushed to `main`.

## Main content

- `_pages/`: website pages
- `_news/`: news items
- `_bibliography/papers.bib`: publications
- `_data/socials.yml`: social links
- `_sass/_custom.scss`: site-specific styling
- `assets/`: profile image, research figures, and CV PDF
